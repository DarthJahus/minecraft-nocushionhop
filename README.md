# No Cushion Hop (Cushion Nerf)

Prevents interacting with a cushion while already seated on one.

This stops the "cushion highway" technique (hopping from cushion to cushion by right-clicking (15 b/s) or using a keyboard to get up to 60 b/s).

## Behavior
- Standing + right-click cushion → sit (vanilla)
- Seated on cushion + right-click another cushion → **blocked**
- Shift to stand, then sit elsewhere
